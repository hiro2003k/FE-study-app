1. 半加算器 & 全加算器

• 半加算器 = XOR (和S) ＋ AND (桁上がりC)

• 全加算器 = 半加算器2個 ＋ OR回路1個（下の桁の繰り上がりも足せる）

2. 状態遷移表（文字列検査）

• 表の「0, 1, 2」は部屋番号（状態ID）！計算値でも2進数でもない！

• 1文字ごとに「次の部屋」へ移動するスゴロク。最後に「受理状態（ゴール）」に着けば合格。

3. 逆ポーランド記法

• 人間用：カッコでくくって、記号を後ろへポイッと投げる！
例: (A + B) × C → ((A B)+ C)× → A B + C ×

• コンピュータ用：スタック（皿）を使い、左から一直線に読む。

4. ハッシュ法と探索時間

• O(1)：データが何億件あっても「1発で直行できる」（計算時間一定）。

• 同じ場所に入ってしまう事故 = 衝突（シノニム）。

• 対比：線形探索=O(n)、2分探索=O(log n)（※事前ソート必須）。

5. データ構造

• スタック：積まれた本、後入れ先出し（LIFO）

• キュー：レジの行列、先入れ先出し（FIFO）

• 配列：下駄箱。番号で即アクセス可、途中の割り込みは全員ずらす大工事。

• 連結リスト：電車。鎖（ポインタ）を繋ぎ変えるだけで挿入・削除が一瞬。

6. MIL記号 & 万能素子

• Dの形 = AND / 三日月形 = OR / 丸○ = NOT

• NAND / NOR は「万能素子」と呼ばれ、これ1種類だけで全回路が作れる。
